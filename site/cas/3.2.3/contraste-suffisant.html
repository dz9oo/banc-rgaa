3.2.3

Texte large #1b1b1b sur fond blanc

Brouillon Verdict proposé, conforme Déterministe

Test
3.2.3
Modalités
html

Motif

Le seul texte fait 32 px, graisse 400, couleur #1b1b1b sur fond #ffffff déclaré sur le même élément. Le rapport est 17,22:1, au-dessus de 3:1. Il n'y a pas d'autre texte sans graisse d'au moins 24 px. Le test 3.2.3 est tenu pour conforme. Le texte de moins de 24 px relève du test 3.2.1, le gras du test 3.2.4. Le cas reste brouillon et le verdict ne sert pas encore de référence.

Cibles

  • p 32 px, graisse 400

Pièges

  • Appliquer le seuil de 4,5:1 à un texte sans graisse déjà assez grand pour le seuil de 3:1.
