3.2.1

Texte #333333 sur fond blanc

Revu Conforme Déterministe

Test
3.2.1
Modalités
html
Relecture
22 octobre 2026

Motif

Le seul texte fait 16 px, graisse 400, couleur #333333 sur fond #ffffff déclaré sur le même élément. Le rapport est 12,63:1, au-dessus de 4,5:1. Il n'y a pas de texte en image. Le test 3.2.1, qui porte sur le texte sans graisse de moins de 24 px, est validé. Relecture sur la page du test le 22 octobre 2026.

Cibles

  • p Seul texte de la page

Pièges

  • Un fond uni posé sur le même élément se calcule. Un texte peint dans une image ne se voit pas dans la feuille de style.
