3.2.1

Texte gris #777777 sur fond blanc

Revu Non conforme Déterministe

Test
3.2.1
Modalités
html

Motif

Le seul texte fait 16 px, graisse 400, couleur #777777 sur fond #ffffff déclaré sur le même élément. Le rapport de ces deux couleurs est 4,48:1, sous le seuil de 4,5:1 du test 3.2.1. Aucun mécanisme ne propose un autre contraste. Le test n'est pas validé. Relecture sur la page du test le 22 octobre 2026.
