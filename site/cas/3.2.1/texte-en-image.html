3.2.1

Texte peint dans une image, contraste insuffisant

Revu Non conforme Vision

Test
3.2.1
Modalités
html, capture

Motif

Le seul texte visible est peint dans texte.png : #b4b4b4 sur #ffffff, 16 px, graisse 400, rapport 2,07:1. La page HTML ne déclare pas ces couleurs. La capture montre le rendu. Le test 3.2.1 inclut le texte en image sous 24 px sans graisse. Le seuil 4,5:1 n'est pas atteint. Relecture sur la page du test le 22 octobre 2026.

Pièges

  • Lire seulement les couleurs CSS rate ce cas : le texte jugé est dans les pixels de l'image.
