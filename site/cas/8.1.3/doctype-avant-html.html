8.1.3

Doctype placé avant l'élément html

Brouillon Verdict proposé, conforme Déterministe

Test
8.1.3
Modalités
html

Motif

La déclaration <!DOCTYPE html> est le premier nœud du fichier, avant la balise html. Le test 8.1.3 demande cette place pour une page qui possède un doctype. Le test est tenu pour conforme. La validité du type est le test 8.1.2. Le cas reste brouillon et le verdict ne sert pas encore de référence.

Pièges

  • Regarder le rendu du navigateur pour décider de la place du doctype dans le source.
