Motif

Le formulaire a un bouton dont le texte visible est « Envoyer le message », sans aria-label. L'intitulé décrit l'action, et le nom accessible est ce même texte. Le test 11.9.1, pertinence de l'intitulé et du nom, est validé. Relecture sur la page du test le 22 octobre 2026.
