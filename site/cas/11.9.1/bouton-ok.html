Bouton « OK » pour envoyer un message

Motif

Le formulaire sert à envoyer un message. Le bouton visible porte « OK », sans autre nom. Cet intitulé ne décrit pas l'action produite par l'activation. Le test 11.9.1 n'est pas validé. Le test 11.9.2, qui compare le nom accessible au texte visible, n'est pas jugé ici. Relecture sur la page du test le 22 octobre 2026.
