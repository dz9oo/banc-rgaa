Document sans doctype

Verdict : Non conforme. Nature : Déterministe. Statut : Revu.

Test
8.1.1
Modalités
html

Motif

Le fichier commence par l'élément html. Aucun doctype ne le précède. Le test 8.1.1 demande un doctype placé avant html et un type de document valide. Les deux manquent. Relecture sur la page du test le 22 octobre 2026.
