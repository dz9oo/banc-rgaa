8.1.1

Doctype HTML avant l'élément html

Revu Conforme Déterministe

Test
8.1.1
Modalités
html

Motif

Le document commence par <!DOCTYPE html>, avant l'élément html. Le test 8.1.1 demande un doctype placé avant html et un type de document valide. Cette déclaration est le type HTML cité en exemple par le test. Relecture sur la page du test le 22 octobre 2026.
