Lien sans contenu

Verdict : Non conforme. Nature : Déterministe. Statut : Revu.

Test
6.2.1
Modalités
html

Motif

Le seul lien est un élément a sans texte et sans alternative dans son contenu. Un contour CSS le rend visible à l'écran. Ce contour n'est pas un intitulé. Le test 6.2.1 demande un intitulé dans le contenu de l'élément. Relecture sur la page du test le 22 octobre 2026.

Pièges

  • Un contour CSS rend le lien visible. Il ne constitue pas l'intitulé demandé dans le contenu de l'élément.
