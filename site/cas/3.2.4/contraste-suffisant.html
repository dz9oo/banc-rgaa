3.2.4

Titre gras #1b1b1b sur fond blanc

Brouillon Verdict proposé, conforme Déterministe

Test
3.2.4
Modalités
html

Motif

Le titre fait 32 px, graisse 700, couleur #1b1b1b sur fond #ffffff déclaré sur le même élément. La taille restituée dépasse 18,5 px. Le rapport est 17,22:1, au-dessus de 3:1. Le test 3.2.4 est tenu pour conforme. Un texte gras de moins de 18,5 px relèverait du test 3.2.2. Le cas reste brouillon et le verdict ne sert pas encore de référence.

Pièges

  • Appliquer le seuil de 4,5:1 à un texte gras déjà assez grand pour le seuil de 3:1.
