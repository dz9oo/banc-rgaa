Aucune indication de langue

Verdict : Non conforme. Nature : Déterministe. Statut : Revu.

Test
8.3.1
Modalités
html

Motif

Ni html ni le paragraphe ne portent lang ou xml:lang. Le test 8.3.1 demande une indication de langue par défaut, sur html pour le HTML, ou à défaut sur chaque passage de texte. La page contient un paragraphe. Relecture sur la page du test le 22 octobre 2026.
