8.3.1

Langue française indiquée sur html

Revu Conforme Déterministe

Test
8.3.1
Modalités
html

Motif

L'élément html porte lang="fr" et la page contient un paragraphe. Le test 8.3.1 demande une indication de langue par défaut. Pour un document HTML, l'attribut lang sur html répond à cette demande. La pertinence du code de langue est un autre test. Relecture sur la page du test le 22 octobre 2026.
