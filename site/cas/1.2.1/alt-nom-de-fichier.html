1.2.1

Filet décoratif dont l'alt est un nom de fichier

Revu Non conforme Pertinence

Test
1.2.1
Modalités
html
Relecture
22 octobre 2026

Motif

L'image est le même filet, sans information et sans légende. alt vaut « filet.png », et l'image n'a ni aria-hidden ni role="presentation". Le test 1.2.1 n'est pas validé : l'image décorative n'est pas ignorée. Relecture sur la page du test le 22 octobre 2026.

Pièces visuelles

Cibles

  • img Même filet, alt renseigné

Pièges

  • Un alt non vide sur une image décorative expose un texte inutile aux technologies d'assistance.

Autres cas de ce test

  • Revu Conforme Filet décoratif avec alt vide
  • Brouillon Verdict proposé, non applicable Page sans image de décoration
