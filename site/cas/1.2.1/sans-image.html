1.2.1

Page sans image de décoration

Brouillon Verdict proposé, non applicable Pertinence

Test
1.2.1
Modalités
html

Motif

La page ne contient aucune balise img. Le test 1.2.1 vise les images img décoratives sans légende, et demande un alt vide sans autre nom, ou aria-hidden, ou role presentation. Aucune image de ce type n'est là : le test est non applicable. Le cas reste brouillon et le verdict ne sert pas encore de référence.

Pièges

  • Traiter l'absence d'image comme une image décorative non conforme.

Autres cas de ce test

  • Revu Non conforme Filet décoratif dont l'alt est un nom de fichier
  • Revu Conforme Filet décoratif avec alt vide

Spécimen. La page jugée n’est pas modifiée.
