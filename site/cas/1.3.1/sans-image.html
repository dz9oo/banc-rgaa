Page sans image porteuse d'information

Verdict : Non applicable. Nature : Pertinence. Statut : Brouillon.

Test
1.3.1
Modalités
html

Motif

La page ne contient aucune balise img ni aucun role img. Le test 1.3.1 juge la pertinence d'une alternative déjà présente sur une image porteuse d'information. Aucune image de ce type n'est là : le test est non applicable. L'absence d'alternative, lorsqu'une image existe, est un autre test. Le cas reste brouillon et le verdict ne sert pas encore de référence.

Pièges

  • Juger la pertinence d'une alternative qui n'existe pas parce que l'image n'existe pas.
