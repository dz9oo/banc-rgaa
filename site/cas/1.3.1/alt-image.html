Alternative « image » pour un nombre

Verdict : Non conforme. Nature : Pertinence. Statut : Revu.

Test
1.3.1
Modalités
html

Motif

L'image affiche le nombre 12, qui n'est pas répété dans le texte. Une alternative est présente, le mot « image », mais elle ne reprend pas l'information. Le test 1.3.1 n'est pas validé. L'absence totale d'alternative serait le test 1.1.1, qui n'est pas jugé ici. Relecture sur la page du test le 22 octobre 2026.
