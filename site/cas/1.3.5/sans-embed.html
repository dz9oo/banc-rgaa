1.3.5

Page sans image embarquée informative

Brouillon Verdict proposé, non applicable Pertinence

Test
1.3.5
Modalités
html

Motif

La page ne contient aucune balise embed de type image. Le test 1.3.5 juge la pertinence de l'alternative ou du contenu alternatif d'une image embarquée porteuse d'information. Aucun embed n'est là : le test est non applicable. Le cas reste brouillon et le verdict ne sert pas encore de référence.

Pièges

  • Conclure non conforme alors que l'élément visé par le test est absent de la page.

Page minimale

Spécimen. La page jugée n’est pas modifiée.
