aria-label qui ne contient pas le texte visible

Verdict : Non conforme. Nature : Déterministe. Statut : Revu.

Test
11.9.2
Modalités
html

Motif

Le bouton affiche « Envoyer le message » et porte aria-label="Valider". Le nom accessible est « Valider », qui ne contient pas l'intitulé visible. Le test 11.9.2 n'est pas validé. Relecture sur la page du test le 22 octobre 2026.

Pièges

  • Un aria-label remplace le texte visible dans le nom accessible. Le texte peut rester pertinent pendant que le test 11.9.2 échoue.
