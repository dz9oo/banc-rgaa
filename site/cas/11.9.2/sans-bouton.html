Page sans bouton, test du nom accessible

Verdict : Non applicable. Nature : Déterministe. Statut : Revu.

Test
11.9.2
Modalités
html

Motif

La page ne contient ni formulaire ni bouton. Le test 11.9.2 cherche les boutons d'un formulaire pour comparer le nom accessible et l'intitulé visible. Il n'y en a pas : le test est non applicable. Relecture sur la page du test le 22 octobre 2026.
