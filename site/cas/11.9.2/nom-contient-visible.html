11.9.2

Le nom accessible est le texte du bouton

Revu Conforme Déterministe

Test
11.9.2
Modalités
html
Relecture

Motif

Le bouton affiche « Envoyer le message » et ne porte ni aria-label ni aria-labelledby. Le nom accessible est donc ce texte visible, qui le contient. Le test 11.9.2 est validé. La pertinence de l'intitulé est le test 11.9.1. Relecture sur la page du test le 22 octobre 2026.
