Protocole 1.2.3

Nature : Pertinence.

Test dans la méthode officielle

Ce qu'une machine peut établir

Un programme peut voir si un object de type image existe, et lire aria-hidden ainsi que le texte qu'il contient. Il ne décide pas que l'objet est décoratif.

Ce qu'une personne tranche

Une personne décide que l'objet n'apporte aucune information, puis vérifie les trois conditions du test. Ici, elle constate qu'aucun object n'existe.

Environnement

La page, ouverte comme source. Le lot ne contient pas de balise object.

Ce qui se tranche

Le test vise les images objet décoratives sans légende. Le lot montre une page qui n'en a pas, tenue pour non applicable.

Cas du banc : 1.2.3/sans-objet.

Pièges

  • Confondre une image img avec une image objet.
