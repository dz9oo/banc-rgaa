Protocole 3.2.5

Nature : Déterministe.

Test dans la méthode officielle

Ce qu'une machine peut établir

Un programme peut voir si un contrôle propose un autre couple de couleurs, et calculer le contraste du texte de ce contrôle.

Ce qu'une personne tranche

Une personne confirme que le contrôle sert à afficher un contraste conforme, puis en juge le texte.

Environnement

Page rendue. Le lot ne contient pas de contrôle de ce type.

Ce qui se tranche

Le test ne s'ouvre que lorsqu'un mécanisme permet d'afficher un contraste conforme. Le lot montre une page sans ce mécanisme, tenue pour non applicable.

Cas du banc : 3.2.5/sans-mecanisme.

Pièges

  • Rejeter la page parce que les couleurs sont fixes, alors que le test vise le mécanisme.
