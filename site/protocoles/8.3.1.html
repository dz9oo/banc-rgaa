Protocole 8.3.1

Nature : Déterministe.

Test dans la méthode officielle

Ce qu'une machine peut établir

Un programme peut lire l'attribut lang sur html, et voir si un passage de texte en est dépourvu.

Ce qu'une personne tranche

Une personne confirme que l'indication trouvée est bien celle de la langue par défaut du document, pas celle d'un passage isolé jugé ailleurs.

Environnement

Le fichier source. La page du lot contient un paragraphe, pour que l'absence de langue ait un texte à couvrir.

Ce qui se tranche

Le test demande une indication de langue par défaut. Pour le HTML du lot, c'est lang sur html. L'absence sur html et sur le texte est un échec. La pertinence du code choisi est un autre test.

Cas du banc : 8.3.1/langue-absente, 8.3.1/langue-fr.

Pièges

  • Accepter n'importe quelle valeur de lang valide le présent test et laisse ouverte la pertinence du code.
  • Une page sans aucun texte ne démontre pas le cas d'absence.

Banc d'essai communautaire pour le RGAA 4.1.2. Les verdicts revus sont des lectures contributives, reliées à la méthode officielle. Ce site ne signe pas une conformité.
