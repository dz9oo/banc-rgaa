Protocole

1.2.4

Pertinence

Chaque image vectorielle (balise <svg>) de décoration, sans légende, vérifie-t-elle ces conditions ?

Test officiel 1.2.4

Ce qu’une machine peut établir

Un programme peut voir si une balise svg est dans le HTML, et lire aria-hidden, title, desc et les noms. Il ne décide pas que le dessin est décoratif.

Ce qu’une personne tranche

Une personne décide que l'image vectorielle n'apporte aucune information, puis vérifie qu'elle sera ignorée. Ici, elle constate qu'aucune balise svg n'existe.

Environnement

La page, ouverte comme source. Une image svg appelée par img ne compte pas comme balise svg.

Ce qui se tranche

Le test vise les svg décoratifs sans légende. Le lot montre une page qui n'a pas de balise svg, tenue pour non applicable.

Cas du banc : 1.2.4/sans-svg.

Pièges

  • Traiter le fichier svg d'une balise img comme si la balise svg était dans la page.
