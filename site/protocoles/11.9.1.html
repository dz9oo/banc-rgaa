Protocole 11.9.1

Nature : Pertinence.

Test dans la méthode officielle

Ce qu'une machine peut établir

Un programme peut lire le texte visible du bouton et son nom accessible. Il ne décide pas que cet intitulé décrit l'action.

Ce qu'une personne tranche

Une personne vérifie que l'intitulé visible et le nom accessible disent l'action produite.

Environnement

Le formulaire dans un navigateur. Le lot utilise un bouton submit.

Ce qui se tranche

Le test porte sur la pertinence, pas sur la seule égalité entre visible et nom. Le lot oppose « Envoyer le message », « OK », et une page sans bouton tenue pour non applicable.

Cas du banc : 11.9.1/bouton-ok, 11.9.1/envoyer-le-message, 11.9.1/sans-bouton.

Pièges

  • Accepter « OK » parce qu'un h1 voisin parle du contact : le test lit l'intitulé du bouton.
  • Valider le test à vide lorsqu'aucun bouton n'existe. Le banc marque alors non applicable.

Banc d'essai communautaire pour le RGAA 4.1.2. Les verdicts revus sont des lectures contributives, reliées à la méthode officielle. Ce site ne signe pas une conformité.
