Protocole

1.3.1

Pertinence

Chaque image (balise <img> ou balise possédant l’attribut WAI-ARIA role="img") porteuse d’information, ayant une alternative textuelle, cette alternative est-elle pertinente (hors cas particuliers) ?

Test officiel 1.3.1

Ce qu’une machine peut établir

Un programme peut extraire l'alternative déjà présente. Il ne décide pas qu'elle reprend l'information de l'image.

Ce qu’une personne tranche

Une personne compare l'information visible de l'image et le texte de l'alternative.

Environnement

La page et le fichier image. Le nombre affiché n'est pas répété dans le HTML.

Ce qui se tranche

Le test suppose une alternative déjà là, et en juge la pertinence. Le lot oppose une alternative qui reprend le nombre et le mot « image ». L'absence d'alternative est un autre test. Une page sans image porteuse d'information est non applicable.

Cas du banc : 1.3.1/alt-image, 1.3.1/alt-pertinent, 1.3.1/sans-image.

Pièges

  • Confondre ce test avec l'absence d'alternative.
  • Accepter un alt générique dès qu'il n'est pas vide.
