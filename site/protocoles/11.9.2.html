Protocole 11.9.2

Nature : Déterministe.

Test dans la méthode officielle

Ce qu'une machine peut établir

Un programme peut calculer le nom accessible et voir s'il contient l'intitulé visible.

Ce qu'une personne tranche

Une personne vérifie l'intitulé réellement affiché, surtout quand il est porté par une image de texte.

Environnement

Le bouton dans un navigateur, inspecteur utile pour lire aria-label.

Ce qui se tranche

Le test compare deux chaînes. Le lot oppose un bouton dont le nom est le texte visible, un aria-label qui le remplace, et une page sans bouton non applicable. La pertinence du libellé est le test 11.9.1.

Cas du banc : 11.9.2/nom-contient-visible, 11.9.2/nom-remplace-visible, 11.9.2/sans-bouton.

Pièges

  • Croire qu'un intitulé visible pertinent suffit lorsque aria-label le remplace.
  • Juger ici la pertinence du mot « Valider », qui n'est pas la question de ce test.
