Protocole

1.2.5

Pertinence

Chaque image bitmap (balise <canvas>) de décoration, sans légende, vérifie-t-elle ces conditions ?

Test officiel 1.2.5

Ce qu’une machine peut établir

Un programme peut voir si une balise canvas existe, et lire aria-hidden ainsi que le texte entre les balises. Il ne décide pas que le dessin est décoratif.

Ce qu’une personne tranche

Une personne décide que l'image bitmap n'apporte aucune information, puis vérifie qu'elle sera ignorée. Ici, elle constate qu'aucun canvas n'existe.

Environnement

La page, ouverte comme source. Le lot ne contient pas de balise canvas.

Ce qui se tranche

Le test vise les canvas décoratifs sans légende. Le lot montre une page qui n'en a pas, tenue pour non applicable.

Cas du banc : 1.2.5/sans-canvas.

Pièges

  • Chercher le dessin dans un script alors que le test lit la balise canvas.
