Protocole

8.1.1

Déterministe

Pour chaque page web, le type de document (balise doctype) est-il présent ?

Test officiel 8.1.1

Ce qu’une machine peut établir

Un programme peut voir si un doctype est présent et s'il est placé avant l'élément html. Il peut reconnaître la déclaration HTML citée par le test.

Ce qu’une personne tranche

Une personne confirme que le type annoncé est un type de document valide, au-delà de la seule présence d'une chaîne doctype.

Environnement

Le fichier source, ouvert comme texte. Pas de rendu nécessaire.

Ce qui se tranche

Le test demande un doctype avant html et un type valide. Le lot oppose la déclaration HTML de l'exemple officiel à un fichier qui commence par html.

Cas du banc : 8.1.1/doctype-absent, 8.1.1/doctype-html.

Pièges

  • Un doctype quelconque, même placé au bon endroit, n'est pas forcément un type valide.
  • Le rendu du navigateur ne montre pas le doctype.
