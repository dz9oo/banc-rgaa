Protocole 6.1.5

Nature : Déterministe.

Test dans la méthode officielle

Ce qu'une machine peut établir

Un programme peut comparer l'intitulé visible du lien et le nom accessible calculé depuis le contenu, aria-label et aria-labelledby.

Ce qu'une personne tranche

Une personne confirme que tout le texte visible du lien, y compris celui d'une image, est repris dans le nom accessible.

Environnement

Le source du lien. Pas de technologie d'assistance. Le lot utilise un lien texte sans aria-label.

Ce qui se tranche

Le test demande que le nom accessible contienne l'intitulé visible. Le lot montre un lien dont le nom est exactement ce texte. Le caractère explicite de l'intitulé est le test 6.1.1.

Cas du banc : 6.1.5/nom-contient-visible.

Pièges

  • Accepter un nom accessible qui remplace l'intitulé visible par une autre formulation.
