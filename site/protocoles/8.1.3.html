Protocole

8.1.3

Déterministe

Pour chaque page web possédant une déclaration de type de document, celle-ci est-elle située avant la balise <html> dans le code source ?

Test officiel 8.1.3

Ce qu’une machine peut établir

Un programme peut voir si le doctype est placé avant l'élément html dans le source. Le rendu ne montre pas cette place.

Ce qu’une personne tranche

Une personne confirme l'ordre dans le fichier lorsque la déclaration est inhabituelle ou commentée.

Environnement

Le fichier source, ouvert comme texte. Pas de rendu nécessaire.

Ce qui se tranche

Le test demande que le doctype, lorsqu'il existe, précède la balise html. Le lot montre la déclaration HTML en tête de fichier.

Cas du banc : 8.1.3/doctype-avant-html.

Pièges

  • Décider de la place du doctype en regardant la page rendue.
