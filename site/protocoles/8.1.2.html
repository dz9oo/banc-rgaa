Protocole

8.1.2

Déterministe

Pour chaque page web, le type de document (balise doctype) est-il valide ?

Test officiel 8.1.2

Ce qu’une machine peut établir

Un programme peut lire la déclaration de type et la comparer au doctype HTML. Il ne se fonde pas sur le rendu.

Ce qu’une personne tranche

Une personne confirme que le type annoncé est un type de document valide, au-delà de la seule présence d'une chaîne doctype.

Environnement

Le fichier source, ouvert comme texte. Pas de rendu nécessaire.

Ce qui se tranche

Le test demande un type de document valide. Le lot retient la déclaration HTML. La présence est le test 8.1.1, la place avant html est le test 8.1.3.

Cas du banc : 8.1.2/doctype-html.

Pièges

  • Accepter un doctype inventé parce qu'il est placé au bon endroit.
