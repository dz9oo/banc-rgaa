Protocole

1.3.4

Pertinence

Pour chaque image objet (balise <object> avec l’attribut type="image/…") porteuse d’information, ayant une alternative textuelle ou un contenu alternatif, cette alternative est-elle pertinente (hors cas particuliers) ?

Test officiel 1.3.4

Ce qu’une machine peut établir

Un programme peut extraire title, aria-label, aria-labelledby et le contenu d'un object de type image. Il ne décide pas que ce texte est pertinent.

Ce qu’une personne tranche

Une personne compare l'information de l'objet et son alternative. Ici, elle constate qu'aucun object n'existe.

Environnement

La page, ouverte comme source. Le lot ne contient pas de balise object.

Ce qui se tranche

Le test suppose une image objet porteuse d'information qui a déjà une alternative ou un contenu alternatif. Le lot montre une page sans objet, tenue pour non applicable.

Cas du banc : 1.3.4/sans-objet.

Pièges

  • Confondre une image img avec une image objet.
