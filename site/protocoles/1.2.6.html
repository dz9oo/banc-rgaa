Protocole

1.2.6

Pertinence

Chaque image embarquée (balise <embed> avec l’attribut type="image/…") de décoration, sans légende, vérifie-t-elle ces conditions ?

Test officiel 1.2.6

Ce qu’une machine peut établir

Un programme peut voir si un embed de type image existe, et lire aria-hidden ainsi que les noms. Il ne décide pas que l'image est décorative.

Ce qu’une personne tranche

Une personne décide que l'image embarquée n'apporte aucune information, puis vérifie qu'elle sera ignorée. Ici, elle constate qu'aucun embed n'existe.

Environnement

La page, ouverte comme source. Le lot ne contient pas de balise embed.

Ce qui se tranche

Le test vise les images embarquées décoratives sans légende. Le lot montre une page qui n'en a pas, tenue pour non applicable.

Cas du banc : 1.2.6/sans-embed.

Pièges

  • Confondre une image img avec une image embarquée.
