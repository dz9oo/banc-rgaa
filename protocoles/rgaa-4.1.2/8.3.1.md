## Environnement

Le fichier source. La page du lot contient un paragraphe, pour que l'absence de langue ait un texte à couvrir.

## Ce qui se tranche

Le test demande une indication de langue par défaut. Pour le HTML du lot, c'est lang sur html. L'absence sur html et sur le texte est un échec. La pertinence du code choisi est un autre test.

Cas du banc : `8.3.1/langue-absente`, `8.3.1/langue-fr`.

## Pièges

- Accepter n'importe quelle valeur de lang valide le présent test et laisse ouverte la pertinence du code.
- Une page sans aucun texte ne démontre pas le cas d'absence.
