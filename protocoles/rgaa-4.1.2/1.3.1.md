## Environnement

La page et le fichier image. Le nombre affiché n'est pas répété dans le HTML.

## Ce qui se tranche

Le test suppose une alternative déjà là, et en juge la pertinence. Le lot oppose une alternative qui reprend le nombre et le mot « image ». L'absence d'alternative est un autre test.

Cas du banc : `1.3.1/alt-image`, `1.3.1/alt-pertinent`.

## Pièges

- Confondre ce test avec l'absence d'alternative.
- Accepter un alt générique dès qu'il n'est pas vide.
