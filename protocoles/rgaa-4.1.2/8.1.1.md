## Environnement

Le fichier source, ouvert comme texte. Pas de rendu nécessaire.

## Ce qui se tranche

Le test demande un doctype avant html et un type valide. Le lot oppose la déclaration HTML de l'exemple officiel à un fichier qui commence par html.

Cas du banc : `8.1.1/doctype-absent`, `8.1.1/doctype-html`.

## Pièges

- Un doctype quelconque, même placé au bon endroit, n'est pas forcément un type valide.
- Le rendu du navigateur ne montre pas le doctype.
