# Code de conduite

Ce dépôt accueille des personnes qui auditent, qui écrivent des outils, ou qui évaluent un modèle. La discussion porte sur les cas, les protocoles et les verdicts.

## Attendus

- Écrire en français, ou ajouter un résumé français si la contribution est dans une autre langue.
- Critiquer un verdict, un motif ou une page. La critique vise le cas.
- Décrire un désaccord par deux lectures. Un cas limite se publie `non_tranche` plutôt que d'effacer l'une des lectures.
- Refuser les pages de services réels, les données personnelles, les captures d'écran de personnes, et les copies de sites clients.
- Relire un cas `revu` par quelqu'un d'autre que la personne qui l'a écrit.

## Inacceptables

Insultes, harcèlement, publication de données personnelles, et réutilisation du dépôt pour laisser croire à une certification officielle.

## Signalement

Ouvrir une issue, ou écrire aux personnes qui maintiennent le dépôt par le moyen indiqué sur leur profil GitHub. Une contribution qui contrevient à ce code peut être retirée.
